# checkers
This repository serves as a space for me to collaborate with my 12-year-old son. He has a lot of free time because his online school in New Zealand only assigns a few tasks. We plan to develop a game that helps users learn about programming languages and basic HTML. 
The repo is about a game that will exclusively utilize efficient JavaScript, CSS, and HTML. We will start by teaching HTML tags and then move on to the fundamentals of JavaScript and default events. After that, we will explore topics such as variables, loops, and conditional statements.
